# Two color themes

Only Lime Soda and Solar Flare are shipped. The local SVG graphics are authored for Miracle using the user-provided palette references, with soft gradients and ribbed-glass highlights. They contain no labels, watermarks, external resources or landscape photographs.

| Theme | Colors |
| --- | --- |
| Lime Soda | `#00B8FF`, `#2BE0A0`, `#C6FF3D`, `#FFE53B` |
| Solar Flare | `#FF5A1F`, `#FF2E63`, `#FFB020`, `#FF8A00` |

Both graphics use a 2560 × 1440 viewBox and scale without a separate thumbnail. Miracle's MIT license applies to these authored SVG files.
