READY WHEN YOU ARE

Set up. Connect. Create.

Install on Windows 10 or 11 with Python 3.10+, Chrome or Edge, and Roblox Studio. Download the ZIP, then follow these five steps.

Download the release Русская инструкция Source on GitHub
  1. 01

    Download. Extract both folders.

    Choose the helium-mcp ZIP from the release assets and use Extract all. Keep plugin and release next to each other.

  2. 02

    Load the browser plugin.

    Open chrome://extensions or edge://extensions. Enable Developer mode, select Load unpacked and choose the plugin folder containing manifest.json.

  3. 03

    Give Studio the green light.

    Open your place in Roblox Studio. In Assistant, select … → Manage MCP Servers → Enable Studio as MCP Server.

  4. 04

    Start your local bridge.

    Install Python 3.10+ if needed, then open release and run run.bat. The workspace opens at 127.0.0.1:19731/app. Wait for Studio connected.

  5. 05

    Open a chat. Start creating.

    Refresh your AI chat, choose Helium → Start session, then describe your idea. For Notion use Notion AI chat; for ClickUp use Brain Chat.

What does Helium actually connect?

It connects supported browser AI chats to Roblox Studio's built-in MCP server through a local Python bridge. Studio advertises the tools it makes available; Helium passes tool requests and results between your chat and Studio.

Do I need an API key?

Helium doesn't ask for an AI API key. You use your existing supported chat service and its account. The bridge generates a separate local access token automatically; keep that token on your computer.

Does everything stay on my computer?

The bridge runs locally. Studio tool requests and results are exchanged with the online AI chat you choose, so that service's data policies still apply. Local usage tracking stores aggregate counts and hostnames, without saving prompts, code, or tool results.

Which systems are supported?

The current launcher is for Windows 10 and 11, with Python 3.10+, Microsoft Edge or Google Chrome, and a Roblox Studio build that includes Studio MCP. Supported chat hosts are listed in the extension manifest and project documentation.

Is Helium open source?

Yes. Helium’s source is available on GitHub under the MIT license. Fonts and icons retain their licenses. The two palette graphics are authored for Helium.
