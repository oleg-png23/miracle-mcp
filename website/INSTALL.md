# Установка Helium MCP

Нужны Windows 10/11, Python 3.10 или новее, Chrome либо Edge и Roblox Studio со встроенным Studio MCP.

## 1. Распакуйте архив целиком

Скачайте `helium-mcp-2.9.3.zip` из релиза Helium и выберите «Извлечь всё».

Helium — новое название Miracle. Чтобы сохранить настройки расширения, замените файлы в уже подключённой папке **plugin/**, нажмите «Обновить» у этого расширения и обновите вкладки чатов. Старые инструкции с `miracles_tool` и `miracle_tool` по-прежнему поддерживаются. Адреса репозитория и сайта не изменились.
Внутри находятся ровно две папки:

| Папка | Для чего нужна |
| --- | --- |
| `plugin` | Расширение браузера. В ней лежит `manifest.json`. |
| `release` | Локальный мост. В ней лежит `run.bat`. |

Сохраните папки рядом друг с другом. Запускайте файлы после распаковки, а не из окна ZIP.

## 2. Установите расширение браузера

1. В адресной строке Chrome откройте `chrome://extensions`, в Edge — `edge://extensions`.
2. Включите «Режим разработчика» (Developer mode).
3. Нажмите «Загрузить распакованное расширение» (Load unpacked).
4. Выберите именно папку **`plugin`**, внутри которой находится `manifest.json`.
5. При желании закрепите Helium в меню расширений браузера.

## 3. Включите MCP в Roblox Studio

1. Откройте свой проект в Roblox Studio.
2. Откройте Assistant.
3. Выберите **… → Manage MCP Servers → Enable Studio as MCP Server**.
4. Оставьте Studio с открытым проектом.

## 4. Запустите локальный мост

1. Если Python ещё не установлен, установите Python 3.10+ с python.org. При установке включите добавление Python в PATH.
2. Откройте папку **`release`** и запустите **`run.bat`**.
3. Дождитесь открытия рабочего пространства по адресу `http://127.0.0.1:19731/app`.
4. В рабочем пространстве проверьте состояние **Studio connected**. Если Studio ещё не подключилась, откройте Connection guide.

`run.bat` сам запускает локальный мост. Устанавливать npm или дополнительные Python-пакеты не требуется.
Токен доступа создаётся локально. Откройте файл **release/python/token.txt** (в исходном коде — **python/token.txt**) и скопируйте токен. В открытом рабочем пространстве вставьте его в **Connection → Advanced connection settings** и сохраните. Затем откройте рабочее пространство расширения значком Helium на панели браузера, вставьте тот же токен в его настройках Connection и сохраните. Повторите это, если после обновления токен моста изменился. Не вставляйте токен в Studio или AI-чат.

Токен передаётся в локальных запросах. Расширения браузера, которым разрешено читать запросы или изменять локальную страницу Helium, могут получить его; предоставляйте такой доступ только доверенным расширениям.

## 5. Начните сессию в AI-чате

1. Откройте поддерживаемый AI-чат, например ChatGPT или Claude, и войдите в свой аккаунт.
2. Обновите вкладку чата, если она была открыта до установки расширения.
3. Нажмите кнопку **Helium → Start session**.
4. Опишите, что нужно сделать в открытом проекте Studio.

Если вы уже вставили инструкции вручную и AI выводит JSON без действий, выберите **Helium → Watch this chat**. Одного JSON в чате недостаточно: должен работать считыватель ответов. Эта кнопка может выполнить последний ответ с инструментом один раз и не заменяет ваш черновик.

Если инструмент отработал, но результат не отправился в чат, откройте **Last tool result → Retry sending result**. Повторяется только отправка результата, сам инструмент заново не запускается. Результат также можно скопировать или закрыть. Обновление вкладки очищает это временное состояние: перед повтором действия проверьте Studio.

В Notion сначала откройте **Notion AI chat**, в ClickUp — **Brain Chat**.

## Если что-то не работает

- **Кнопка Helium не появилась:** проверьте, что расширение включено, и обновите вкладку поддерживаемого чата. Edge ограничивает расширения на странице Copilot; используйте другой поддерживаемый чат.
- **Не найден manifest.json:** выберите распакованную папку `plugin`, а не ZIP, `release` или папку уровнем выше.
- **Рабочее пространство не открывается:** убедитесь, что папки `plugin` и `release` находятся рядом, затем запустите `release/run.bat`.
- **Python не найден:** установите Python 3.10+ и запустите `run.bat` снова. Для своего пути можно задать `HELIUM_PYTHON_PATH`.
- **Studio не подключается:** откройте проект и включите Studio MCP в Assistant. Проверьте подсказку в Connection guide.
- **Повторный запуск:** `run.bat` использует уже работающий мост и предотвращает запуск дубликатов. Распознанная старая версия Helium закрывается перед обновлением. Если процесс не удалось надёжно определить, он не завершается автоматически.
- **Остановка моста:** запустите `release/stop.bat`. Дождитесь завершения текущего инструмента перед остановкой.
- **Studio подключена, но чат ничего не делает:** проверьте блок **Chat agent** на Home. Он показывает состояние считывателя, незавершённый JSON и необходимость обновления расширения или вкладки. Кнопка **Copy connection report** копирует отчёт без токенов, переписки и кода.

После обновления архива перезапустите мост, нажмите «Обновить» у расширения в браузере и перезагрузите вкладки чатов.

Публичный сайт и его превью показывают интерфейс на демонстрационных данных. Для работы с настоящим Studio используйте установленное расширение и локальный мост.
