AN IDEA IS A GOOD START

Three steps.
A world of potential.

You'll need Windows 10 or 11, Python 3.10+, Chrome or Edge, and Roblox Studio with built-in MCP support.

Get the latest release Browse the source on GitHub ↗
  1. 01

    Give Studio the green light.

    Open a place in Roblox Studio. In Assistant, select … → Manage MCP Servers → Enable Studio as MCP Server.

  2. 02

    Start your local connection.

    Download and extract Miracle, then run run.bat. Keep the bridge running while you work.

  3. 03

    Load it. Open a chat. Create.

    Open your browser's Extensions page, enable Developer mode, and Load unpacked from the extracted folder. In a supported chat, choose Miracle → Start session.

Clear answers.

What does Miracle actually connect?

It connects supported browser AI chats to Roblox Studio's built-in MCP server through a local Python bridge. Studio advertises the tools it makes available; Miracle passes tool requests and results between your chat and Studio.

Do I need an API key?

Miracle doesn't ask for an AI API key. You use your existing supported chat service and its account. The bridge generates a separate local access token automatically; keep that token on your computer.

Does everything stay on my computer?

The bridge runs locally. Studio tool requests and results are exchanged with the online AI chat you choose, so that service's data policies still apply. Local usage tracking stores aggregate counts and hostnames, without saving prompts, code, or tool results.

Which systems are supported?

The current launcher is for Windows 10 and 11, with Python 3.10+, Microsoft Edge or Google Chrome, and a Roblox Studio build that includes Studio MCP. Supported chat hosts are listed in the extension manifest and project documentation.

Is Miracle open source?

Yes. Miracle's source code is available on GitHub under the MIT license. Fonts, icons, and landscape assets retain their separate licenses and attribution files.
